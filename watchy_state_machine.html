PowerStateMachine Summary

  • SleepState: Puts the ESP32 into deep sleep to conserve battery.
  • AwakeState: Powers on the display, reads sensors, runs watchy->tick(), and processes UI inputs. Automatically transitions to sleep when ActiveMode goes false.

UiStateMachine Summary

  • WatchfaceState: Default idle mode showing the time, battery, and step count.
  • MenuState: Delegates input to the built-in WatchyGSR menu system.
  • ShowButtonsState: Displays an overlay hint mapping SW1-SW4 physical buttons to their current logical functions. Times out after 10s.
  • MedInfoState: Displays emergency medical info (e.g., Name, ID, Allergies).
  • WeatherState: Displays a full-screen weather report (icon, temperature, sky condition, feels-like, humidity, wind, and pressure) fetched from Open-Meteo.
  • BleRemoteState: Starts a NimBLE server (Watchy4Granny) providing BLE HID Consumer Control media keys (SW3: Vol+, SW4: Vol-, SW1: Play/Pause) and the BLE Digital Twin GATT Service (19b10000-e8f2-537e-4f6c-d104768a1214) for phone-assisted Time Sync, Weather Location Sync, Weather Push, and Status telemetry.
  • FindFoneState: Connects to WiFi and triggers an IFTTT webhook to ping the user's phone.
  • SuspendState: A low-power lock screen triggered when the battery hits critical levels. Forces the UI to sleep to prevent accidental usage but can be temporarily awakened (via SW3) when plugged into a charger.
